abm_analysis.py
    Analyze outputs of abm ll evaluations. Heatmaps of likelihood over parameter values, bayesian estimates of shooting stats, etc. 
abm_eval.py:
    Script for running ll eval over product space of possible parameter values
abm_event.py
    sample_event: Sample outcome of a single event, returns number of deaths from a given event
    conditional_sample: Sample batch of many events at once
abm_ll.py
    poisson_ll: Helper function for ll of poisson distr
    city_ll: Calculates probability of a city's history given city parameters and general parameters. 
    event_rate: Expected number of events w/ more then five fatalities in a given timespan
    eval_ds: Calculate log-likelihood of events in each city given general params and list of city params
abm_mcmc.py
    eval_params: Eval log-likelihood of a set of params with hardcoded city data.
    get_param_density_func: Take in param prior, rng, and num_samples. 
    Return stateless function of parameters that simply gives log-likelihood eval of parameters. 
    Optionally include data-dict to record data from eval process, like city-level log-likelihoods. 
city_data.py
    Load dataset and subsampled dataset for eval. 
county_analysis.ipynb
    Gen city data dataset w/ city params including population, population density, gun density, etc in each county.
    Saves to data/county_data.pkl
forecast.ipynb
    Gen forecasts for cities, expected mass shooting rates, etc
mcmc.py
    mcmc: Custom mcmc implementation that takes in initial params, a proposal func mapping from current state to nearby neighbor, 
        density function, and Q func accounting for potential asymmetry in proposal func. 
        Returns a list of samples and their estimated likelihoods. 
param_distr.py
    Defines a param distr class that keeps track of parameters and the prior over them. Good for sampling and getting prior distr, but
    only for uniform and log-uniform distributions. God help you otherwise. 
plots.ipynb
    A bunch of very nice code from Mira plotting gun sales stores densities. Thanks Mira. 
zip_nn.ipynb
    Code for calculating the nearest neighbors of zip codes using lat long coords. Thanks Mira.
